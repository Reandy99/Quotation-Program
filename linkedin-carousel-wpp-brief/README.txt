WPP LinkedIn Carousel (9 slides)

Cara pakai:
1) Buka file index.html di browser.
2) Untuk pindah slide, tambahkan parameter di URL:
   index.html?slide=1
   index.html?slide=2
   ... sampai 9

Cara export:
- Cara cepat: screenshot tiap slide (1080 x 1350).
- Cara rapi: Print / Save as PDF per slide (browser), lalu gabungkan jadi 1 PDF carousel.

Edit konten:
- Ubah teks di slides.js (bagian window.SLIDES_DATA).

Catatan:
- Template ini sengaja minimalis dan konsisten (hitam/putih + accent gold).
- Kalau kamu kirim logo (PNG transparan) dan warna brand pilihan, aku bisa rapikan versi finalnya.
