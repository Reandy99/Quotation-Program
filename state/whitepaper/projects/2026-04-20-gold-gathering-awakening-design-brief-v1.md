# GOLD GATHERING AWAKENING - Design Brief v1

Event: GOLD GATHERING AWAKENING
Date: 18 April 2026
Location: Grand Mercure Kemayoran
Objective: branding + social proof
Design lane: active

## Design intent
Do not present this project as raw event photos only.
Turn selected photos into designed social assets so the post feels more premium, intentional, and campaign-like.

## Reference style from Reandy
Desired direction based on the reference image:
- editorial/social carousel feel
- clean modern layout
- strong typography hierarchy
- photo mixed with text slides
- rounded cards / modular composition
- limited color palette
- business/strategy aesthetic, not noisy event poster style

## Whitepaper brand-guideline alignment
Use `state/whitepaper/brand-guideline-working-v1.md` as the governing design rule for this project.
Priority rules for this batch:
- direct, confident, professional, warm, transparent tone
- white / off-white / charcoal base system
- muted gold accent only when needed
- strong display headline feel + clean supporting sans serif
- no gradients
- no drop shadows
- generous negative space
- short overlay copy only

## Recommended visual direction for Whitepaper
- Keep the event photos as the credibility anchor
- Add minimal text overlays instead of heavy poster treatment
- Use 1 cover slide with strong headline
- Use 1-2 supporting photo slides with short callout text
- Use 1 closing slide with a business takeaway or brand statement

## Suggested palette direction
Whitepaper guideline-aligned direction:
- pure white / off-white
- charcoal / near-black
- warm neutral tones such as warm ash or bone
- muted gold accent, maximum one accent emphasis per design

## Suggested typography direction
- strong condensed display headline feel for key statements
- clean sans serif for supporting text and metadata
- short punchy text, not paragraph-heavy overlays

## Carousel structure options

### Option A - Event recap editorial carousel
1. Cover: event name + one strong line
2. Hero stage photo + short callout
3. Audience/crowd photo + short insight
4. Atmosphere/detail photo + short business takeaway
5. Closing slide: Whitepaper positioning / soft CTA

### Option B - Corporate documentation as business asset
1. Cover: why corporate documentation matters
2. Stage moment
3. Audience scale
4. Brand presence / environment
5. Closing statement about post-event asset value

## Overlay copy direction examples
- More than event photos
- Corporate moments that keep working after the event ends
- Brand presence, captured with intent
- Documentation that becomes a business asset

## Rules for the Design Agent
- design must elevate the photo, not bury it
- avoid overly crowded layouts
- keep event credibility and premium feel
- preserve Whitepaper's professional B2B tone
- favor clean structure over trendy clutter
- make the asset feel like Whitepaper, not a generic template
- optimize for buyer trust and inquiry intent, not just likes

## Handoff to Content + Publishing
- DONI provides short headline/callout copy blocks for slides
- Design Agent maps them into slide structure
- Publishing Agent uses the final designed export set for Instagram carousel or supporting visual assets
