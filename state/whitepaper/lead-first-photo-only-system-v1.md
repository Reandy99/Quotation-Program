# Lead-First Photo-Only System v1

Date: 2026-04-20
Owner directive: Reandy only wants to send event photos; the system should handle the rest.
Primary business goal: new leads -> new sales.

## Operating mode
Input from Reandy can be as light as:
- event photos only
- optional event name/date/location when available

The system must still move forward with sensible defaults.

## Core business rule
The system should not stop at:
- photo archive
- nice caption
- scheduled post

The system should push every strong project toward:
- brand trust
- social proof
- inquiry intent
- future proposal opportunities
- closed sales

## Default flow
1. Reandy sends event photos
2. Exel opens a project intake automatically
3. Research Agent extracts lead-friendly angles
4. DONI creates platform-specific copy
5. Design Agent creates premium visual direction
6. Publishing Agent prepares or schedules posts
7. Analytics Agent tracks what attracts interest
8. Sales follow-up logic turns winning assets into CTA and inquiry paths
9. Exel keeps the loop coherent and user-facing

## Required minimum output per event batch
- angle bank
- LinkedIn draft
- Instagram draft
- Threads draft
- design direction / carousel structure
- CTA direction
- sales follow-up suggestion

## Default assumptions when user only sends photos
- objective: branding + social proof
- likely buyer: corporate marketing, marcom, HR, founder, event lead, decision maker
- commercial aim: future corporate documentation inquiries

## Curation rule for skills/tools
- Prefer first-party local skills when they are safer and more aligned.
- Do not install suspicious external skills just to add volume.
- Only add tools/skills that directly improve the path from content to leads to sales.
