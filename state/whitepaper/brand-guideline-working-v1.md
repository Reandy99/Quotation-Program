# Whitepaper Brand Guideline - Working Extract v1

Source: user-uploaded Whitepaper brand guideline board
Status: working design rule for agents

## Brand position
- direct
- confident
- professional
- warm
- transparent

## Avoid
- wordy / over-explained copy
- boastful / aggressive tone
- corporate stiff tone
- overly casual / slang-heavy feel
- vague / salesy language

## Palette direction
Use these as the core design family:
- pure white
- off white
- charcoal / near-black
- warm ash / soft neutral gray
- bone / warm beige
- muted gold accent

## Typography direction
Primary headline feel:
- bold condensed uppercase display style
- strong, direct, modern

Supporting text feel:
- clean sans serif
- readable, professional, minimal

## Visual style rules
- natural available light feel when using photography
- clean, architectural or well-composed layouts
- sharp focus and high detail
- neutral to warm tone grading
- white / off-white / black background only for layout system
- maximum 1 gold accent element per design
- single concept focus per asset
- around 70% visual and 30% text rule
- no gradients
- no drop shadows
- generous negative space

## Do
- keep backgrounds clean
- use negative space generously
- use up to 1 gold accent element
- keep headlines short and punchy
- show real work, not stock-feeling visuals
- keep edit style consistent and neutral

## Do not
- use more than 2 typefaces in one design
- use loud color combinations
- use lengthy promotional paragraphs on slides
- use heavy decorative icons or emoji-driven layouts
- use heavy Instagram filter looks on client work

## Social design implication for agents
### Research Agent
- angles should support direct and credible B2B positioning

### DONI / Content Agent
- hooks and captions must stay direct, confident, warm, and clear
- avoid fluffy language and over-selling

### Design Agent
- design should feel premium, minimal, structured, and business-ready
- photo remains the credibility anchor
- overlays should be short and strategic

### Publishing Agent
- prefer carousel structures that preserve whitespace and readability

### Analytics Agent
- review not only engagement but also whether the design/copy combination improves inquiry intent and sales trust

## Review questions
Before approving a design or caption, ask:
1. Does this feel like Whitepaper, not a generic social template?
2. Does it feel direct and professional without becoming stiff?
3. Is the design clean enough to support trust?
4. Would a corporate buyer feel this is premium and credible?
5. Does this move attention closer to inquiry or sales conversation?
