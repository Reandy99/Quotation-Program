# Sales Follow-Up System

Use this skill after content and design are prepared, or when a post/project should support new sales.

## Goal
Turn attention and trust into:
- inquiries
- qualified conversations
- proposal opportunities
- closed projects

## Default follow-up logic
1. Identify the strongest trust signal in the asset.
2. Match it to the likely buyer.
3. Choose the soft CTA.
4. Define the next sales step.
5. Prepare a short follow-up direction for Exel.

## Soft CTA examples
- If your team is preparing an event, we can help plan the documentation direction from the start.
- If you want visuals that still work after the event ends, feel free to discuss the brief.
- If you need corporate documentation that can be reused for recap and branding, we can talk.

## Follow-up outputs
Return these sections:
1. Sales angle
2. Ideal buyer
3. Trust proof in the content
4. Soft CTA
5. Suggested next step
6. Follow-up note for proposal/discussion

## Rules
- Keep follow-up consultative, not pushy.
- Use business usefulness as the bridge to sales.
- Reuse strong event outcomes as proof of capability.
- Prefer clear next-step suggestions over generic 'DM us' language.
