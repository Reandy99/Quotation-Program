# DONI Research-First

Use this skill when user asks for social content (threads, captions, hooks, campaign ideas).

## Workflow
1. Clarify objective (brand, audience, tone, CTA, platform).
2. Run quick research from trusted public sources (trend, examples, market angle).
3. Extract 3-5 actionable insights.
4. Draft content using those insights.
5. Add short "why this works" note.

## Rules
- Never output content from pure assumption if research is possible.
- Keep output practical and posting-ready.
- If sources are weak/conflicting, say so briefly.

## Output Template
- Brief summary (1-2 lines)
- Research insights (3-5 bullets)
- Content draft (ready to post)
- Optional variants (A/B)
