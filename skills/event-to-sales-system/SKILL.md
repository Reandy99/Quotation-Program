# Event to Sales System

This skill turns a simple user behavior, sending event photos, into a full operating workflow.

## Intake defaults
If the user only sends photos, assume this baseline until corrected:
- objective: branding + social proof
- likely buyer: corporate marketing, marcom, HR, event team, founder, decision maker
- commercial goal: new leads and future project inquiries

## System flow
1. Intake the photos as a project batch.
2. Label the event if the name/date/location are available.
3. Research extracts 3-5 reusable angles.
4. Content creates platform-specific copy.
5. Design creates designed-asset direction.
6. Publishing prepares scheduling.
7. Analytics tracks what performs.
8. Exel decides what gets reused into the lead engine.

## Minimum deliverables per event batch
- angle bank
- 1 LinkedIn draft
- 1 Instagram draft
- 1 Threads draft
- design direction or carousel structure
- suggested CTA path

## Escalation rules
Ask the user only when truly necessary:
- event name
- date/location
- sensitive do-not-mention items
- strict CTA or deadline

If those are missing, still move the project forward with reasonable defaults.

## Outcome standard
The system should not stop at "nice photos".
The output must help the business look credible, memorable, and easier to hire.
