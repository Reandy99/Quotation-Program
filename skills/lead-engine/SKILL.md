# Lead Engine

Use this skill whenever the real goal is not just posting, but converting attention into inbound leads and sales.

## Core principle
Every content asset should map to one of these functions:
- attract attention
- build trust
- qualify the buyer
- create inquiry intent
- support sales follow-up

## Default content funnel for event-photo input
1. Raw event photos arrive
2. Research extracts the strongest commercial angles
3. Content converts angles into platform-specific posts
4. Design turns them into premium assets
5. Publishing distributes them to the right platform
6. Analytics measures response
7. Exel decides which winners get reused for lead generation

## Required thinking
For each content batch, define:
- target buyer
- likely pain point
- trust signal inside the asset
- soft CTA
- next sales step

## Good CTA examples
- ask for the brief
- ask to see the event objective
- invite inquiry for corporate documentation
- suggest a consultation or project discussion

## Output format
Return these sections:
1. Buyer target
2. Lead angle
3. Trust signal
4. CTA direction
5. Follow-up suggestion

## Rules
- Do not hard-sell every post.
- Use soft CTAs most of the time.
- Prefer trust-building first, then inquiry generation.
- Reuse strong event documentation as proof of execution quality.
- Build content banks that can support future proposals and outreach.
