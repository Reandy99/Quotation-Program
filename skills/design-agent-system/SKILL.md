# Design Agent System

Use this skill when the user provides photos and wants them turned into designed assets, not raw documentation only.

## Goal
Turn event photos into premium social assets that help generate:
- stronger perceived brand quality
- better saves/shares
- better lead intent
- clearer B2B positioning

## Workflow
1. Start from the business goal, not the photo.
   - default priorities: branding, social proof, lead generation
2. Choose one primary visual angle.
   - event recap
   - social proof
   - brand presence
   - post-event business asset
3. Build a simple asset structure.
   - cover slide
   - 1-2 photo slides with short callouts
   - 1 insight slide or proof slide
   - 1 closing slide with soft CTA or positioning
4. Keep overlays short.
   - short headline
   - one supporting line max when needed
5. Use design to elevate the photo, not bury it.

## Output format
Return these sections when this skill is used:
1. Visual direction
2. Carousel slide structure
3. Overlay copy per slide
4. Design notes
5. Recommended photo pairing

## Rules
- Favor premium editorial layouts over noisy poster layouts.
- Keep typography hierarchy strong and clean.
- Prefer 4-6 slides over bloated carousels.
- For Whitepaper, keep the tone B2B, modern, and polished.
- Design should support sales trust, not just aesthetic appeal.

## Default visual language for Whitepaper
- clean grids
- strong headline slide
- photo + text mix
- light background or neutral background blocks
- restrained accent color
- minimal clutter
