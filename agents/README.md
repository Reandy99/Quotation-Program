# Agents Directory

Per-agent folders so you can see & edit each agent’s files clearly.

- `agents/main/`   → Exel (orchestrator)
- `agents/quanxi/` → Quanxi (coding specialist)
- `agents/doni/`   → DONI (social media specialist)

Inside each folder:
- `NOTES.md`     → catatan khusus agent
- `docs/`        → workflow / dokumentasi agent
- `prompts/`     → prompt khusus agent (kalau ada)

Source lama seperti `Openclaw-whitepaper/` tetap dibiarkan sebagai arsip; versi aktif sebaiknya di-edit dari folder `agents/` ini ke depan.
