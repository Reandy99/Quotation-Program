# Axis — Reference & Tools

## Research Toolkit
- **Web Search:** `firecrawl_search`, `web_search`, `web_fetch`
- **Deep scrape:** `firecrawl_scrape`
- **PDF analysis:** `pdf`
- **Memory:** `memory_search`, `memory_get`

## Research Templates

### Trend Scan Brief
```
## Trend: [name]
- What: [1-2 sentence description]
- Who: [affected audience]
- Why now: [timing driver]
- Evidence: [sources]
- Content angle: [how Whitepaper/HeyReandy can leverage]
- Confidence: [high/medium/low]
```

### Audience Pain Point Analysis
```
## Pain Point: [title]
- Audience: [specific segment]
- Symptom: [what they experience]
- Root cause: [why it happens]
- Current solutions: [what they do now]
- Gap: [what's missing]
- Content hook: [angle for content team]
```

### Competitor/Industry Scan
```
## Scan: [topic]
- Sources: [list]
- Key findings: [3-5 bullets]
- Opportunity: [what we can do differently]
- Data points: [specific numbers/stats]
```
